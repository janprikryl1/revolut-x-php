# Types & Enums Reference (PHP)

Complete type definitions and structure specifications for the `janprikryl/revolutx` PHP SDK.
Online interactive documentation: [https://janprikryl1.github.io/revolut-x-php/api/reference/](https://janprikryl1.github.io/revolut-x-php/api/reference/)

## Class-Based Enums

In PHP 8.0+, all enums are implemented as final classes with string/int constants and helper methods (`all()`, `isValid()`):

### `RevolutX\Types\OrderSide`
```php
final class OrderSide
{
    public const BUY = 'buy';
    public const SELL = 'sell';

    public static function all(): array;
    public static function isValid(string $side): bool;
}
```

### `RevolutX\Types\OrderType`
```php
final class OrderType
{
    public const MARKET = 'market';
    public const LIMIT = 'limit';

    public static function all(): array;
    public static function isValid(string $type): bool;

```

## DTOs

### `RevolutX\Types\FeeEstimate`

Represents fee calculation projections generated by `FeeCalculator::calculate`:

```php
final class FeeEstimate
{
    public string $side;                  // 'buy' | 'sell'
    public string $orderType;             // 'limit' | 'market/immediate-limit'
    public bool $isMaker;                 // true = 0.00%, false = 0.09%
    public string $feeRatePercent;        // e.g. "0.00" or "0.09"
    public string $tradeValueEur;         // e.g. "1000.00"
    public string $estimatedBaseQty;      // e.g. "0.01315789"
    public string $price;                 // e.g. "76000.00"
    public string $feeAmount;             // e.g. "0.0000" or "0.9000"
    public string $feeCurrency;           // "EUR"
    public string $netReceived;           // Amount net of fees
    public string $netReceivedCurrency;   // "BTC" or "EUR"
    public string $explanation;           // Human-readable summary

    public function toArray(): array;
}
```

## API Response Structures (Associative Arrays)

> All numeric amounts returned by Revolut X are string-encoded to preserve high precision.

### Ticker Array
```php
[
    'symbol' => 'BTC/EUR',
    'bid' => '76251.40',
    'ask' => '76258.06',
    'mid' => '76254.73',
    'last_price' => '76264.36',
    'low_24h' => '74500.00',
    'high_24h' => '76800.00',
    'volume_24h' => '12.4500',
]
```

### Order Book Array
```php
[
    'symbol' => 'BTC-EUR',
    'bids' => [
        ['76251.40', '0.45000000'],
        ['76250.00', '1.20000000'],
    ],
    'asks' => [
        ['76258.06', '0.35000000'],
        ['76260.00', '0.80000000'],
    ],

```
